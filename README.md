# مدار آخر

یک بازی آرکید فضایی فارسی؛ سفینه را هدایت کن، از آوار دوری کن و بلورها را جمع کن.

[شروع بازی آنلاین](https://madar-akhar.pages.dev)

## کنترل‌ها

- کلیدهای جهت‌نما یا WASD: حرکت
- موس: هدایت سفینه به سمت نشانگر
- موبایل: لمس و کشیدن یا کلیدهای جهت‌نما
- فاصله یا Escape: مکث و ادامه

بهترین امتیاز روی همین دستگاه ذخیره می‌شود. فایل‌های مستقل بازی در پوشهٔ `game/` هستند.
