# Neon Rift — نمونهٔ اولیهٔ Godot 4

یک بازی سه‌بعدی بقا در میدان نئونی، با نمای بالا و حالت عمودی برای موبایل.

## اجرا

1. Godot Engine نسخهٔ 4.2 یا جدیدتر را باز کنید.
2. از Project Manager گزینهٔ **Import** را بزنید و فایل `project.godot` همین پوشه را انتخاب کنید.
3. پروژه را باز کنید و دکمهٔ اجرای بازی را بزنید.

## کنترل‌ها

- موبایل: نیمهٔ چپ پایین صفحه را بکشید تا حرکت کنید.
- موبایل: سمت راست پایین را لمس کنید و بکشید تا جهت شلیک را تعیین کنید.
- دکمهٔ «جهش»: جهش کوتاه و بی‌ضررشدن موقت.
- رایانه: حرکت با WASD یا کلیدهای جهت؛ جهش با Space.
- شلیک به نزدیک‌ترین دشمن به‌صورت خودکار انجام می‌شود.

## بازی

دشمن‌ها موج‌به‌موج قوی‌تر می‌شوند. با حذف دشمن‌ها XP می‌گیرید و ارتقاها به‌ترتیب قدرت شلیک، سرعت شلیک و جان را افزایش می‌دهند. هر پنج موج یک دشمن نخبۀ قوی‌تر ظاهر می‌شود.

## خروجی اندروید

برای ساخت APK، Android export templates همان نسخهٔ Godot و Android SDK/JDK لازم است. در Godot از **Project → Export** خروجی Android را اضافه کنید و مسیر APK را انتخاب کنید. این پوشه، سورس بازی است و خودش APK ازپیش‌ساخته‌شده نیست.
